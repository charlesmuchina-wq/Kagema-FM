<product_requirements>
The Dragon KARAU AI is a global internet radio application designed to provide a rich, interactive user experience on both mobile and web. Its foundation is a self-sustaining database of over 16,000 radio stations, populated and maintained by an AI-powered backend.

**Core Product Features:**
-   **Automated Data Pipeline:** The system automatically discovers, geocodes, enriches, and validates radio stations. This includes a 12-hour automated scheduler that runs all maintenance tasks.
-   **Multi-Tier Geolocation:** To ensure high data quality, the system uses a fallback strategy for geocoding stations, starting with a high-precision API and falling back to country capital coordinates to achieve over 90% coverage.
-   **Real-Time Services:** Integrates live data for weather (Open-Meteo), trending music (Spotify/Last.fm), and advanced routing (Geoapify Distance Matrix).
-   **Interactive Discovery:** Users can explore stations via a 3D globe and interactive maps, with a nearest stations feature enabled by the Distance Matrix integration.
-   **Comprehensive Monitoring:** A full-featured backend dashboard provides real-time visibility into the health and progress of all automated systems (geocoding, metadata enrichment, stream validation).
</product_requirements>
